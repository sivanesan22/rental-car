# 🚗 Rental Car Management System

A web-based Rental Car Management System developed using Python and Django.

## 📌 Features

- User Registration and Login
- Browse Available Cars
- Car Categories
- Car Booking
- Rental Management
- Admin Dashboard
- Car Management
- Customer Management
- Booking Management

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- MySQL
